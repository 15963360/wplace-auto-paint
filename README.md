# wplace-auto-paint

WPlace 像素画板自动化脚本，针对 [wplace.live](https://wplace.live) 的批量绘画工具。包含一个油猴脚本与一个 Python 模板转换脚本。

## 原理 / 工作流

### 油猴脚本 `wplace-auto-paint-v3-final.js`

脚本运行在 wplace 页面里，复用网站自己的认证。

```
点地图一格 ──► 面板显示 Tl / Px 坐标
手动 PAINT 一次 ──► 捕获认证令牌与绘画请求格式
加载模板 JSON ──► 按瓦片拉取当前画布
差异检测 ──► 只保留和模板不一致的像素
路径规划 ──► 从左上角开始，优先最近的同色点
按批次 POST /paint ──► 同一瓦片内的点合并为一次请求
刷新瓦片缓存、查询充能、随机延迟后进入下一轮
```

核心机制：

- **坐标读取**：点地图任意一格即可，面板会显示并允许复制 `Tl X / Tl Y / Px X / Px Y`。取坐标不需要登录。
- **认证**：每次刷新后必须手动 PAINT 一格。没有令牌无法自动绘画。
- **差异检测**：只画和当前画布不一致的像素。`▶ 免费` 只画色号 1–31；`▶ 全量` 连 32–63 的付费色一起画，未解锁的颜色会跳过。
- **瓦片**：按瓦片拉取当前画布。首次对比若整图都不匹配，会再拉一次再比。
- **错误处理**：遇到验证页会暂停。未解锁的颜色会跳过。限流会等待重试，认证失效则停下并要求重新 PAINT。
- **充能**：每轮查询剩余点数，耗尽时等待恢复。批次大小不能超过当前点数。
- **本地存储**：模板、延迟、单色批次和面板位置会记住。令牌不会保存，刷新后要重新 PAINT。

### 模板转换脚本 `convert_image_to_template.py`

将已映射到 wplace 调色板的 PNG 转为脚本可加载的 JSON。

- 透明像素跳过，不写入模板。
- 其余像素匹配最近的调色板颜色。
- 输出全局坐标、宽高、像素列表。

建议先用 [pepoafonso 转换器](https://pepoafonso.github.io/color_converter_wplace/zh-CN/index.html) 把原图转到 wplace 64 色。跳过也可以，生成器会自行匹配，但颜色可能不准。

## 使用方法

### 1. 准备图片

1. 用原图在 [pepoafonso 转换器](https://pepoafonso.github.io/color_converter_wplace/zh-CN/index.html) 中上传并下载转换后的 PNG。
2. 在 wplace.live 点选图片要放置的**左上角**格子。装上本脚本后，面板「坐标」会显示 `Tl X / Tl Y / Px X / Px Y`，可点「复制」。全局坐标 = `Tl × 1000 + Px`，瓦片大小 1000。

### 2. 生成模板 JSON

```bash
python convert_image_to_template.py
```

按提示输入：

1. PNG 路径
2. 坐标方式：`1` 瓦片+像素，`2` 全局像素。默认 `1`
3. 输出路径，回车则与 PNG 同名
4. 输入 `yes` 生成。完成后窗口会停住，按回车退出

输出示例：

```json
{
  "name": "myart",
  "offsetX": 1647472,
  "offsetY": 838307,
  "width": 64,
  "height": 64,
  "pixelCount": 2048,
  "pixels": [
    { "x": 1647472, "y": 838307, "colorId": 7, "colorHex": "#ED1C24" }
  ]
}
```

### 3. 在浏览器中使用

1. Tampermonkey → 添加新脚本，粘贴 `wplace-auto-paint-v3-final.js`。
2. 打开 https://wplace.live，确认出现 **🎨 自动绘画 1.0.0** 面板。
3. 每次刷新后先手动 PAINT 一格，等面板「认证」变为已捕获。
4. 加载上一步生成的 JSON。
5. 调整参数，点 **▶ 免费** 或 **▶ 全量**。全量需要账号已解锁对应付费色。
6. **⏸** 暂停，**⏹** 停止，**🗑** 清除本地缓存的模板。
7. 若提示验证拦截：完成页面验证后再手动 PAINT 一次。批次过大或间隔过短更容易弹出验证。

## 参数说明

### 油猴面板

| 参数 | 默认 | 说明 |
|------|------|------|
| 延迟 | 3 / 8 秒 | 每批画完后的随机等待，单位秒 |
| 单色批次 | 关闭 | 每批只画一种颜色，未解锁时才能准确跳过该色 |
| px/次 | 5 | 开启单色时的每批像素数；关闭单色时每批固定 1 格。不能超过剩余充能 |
| 调试 | 关闭 | 控制台输出更详细的日志 |

### 模板生成器

| 输入 | 说明 |
|------|------|
| PNG 路径 | 必填 |
| 坐标模式 | `1` 瓦片+像素，`2` 全局像素 |
| 输出路径 | 回车使用与 PNG 同名的 `.json` |
| 确认 | 输入 `yes` 才写入；结束后按回车关闭窗口 |

## 注意事项

- 刷新页面后必须重新手动 PAINT。
- 调色板需与游戏当前色表一致，否则颜色会偏。可画色为 1–63，另加透明。
